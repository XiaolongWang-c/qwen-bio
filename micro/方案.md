# 显微镜图像条件生成方案

## 1. 顶层目标

输入一张参考显微镜图像，生成一张新的 AI 图像，满足：

- 与参考图属于同一种实验结果类型。
- 与参考图保持相似的成像风格。
- 与参考图保持相似的整体结构与布局语义。
- 生物前景信息与参考图不同。
- 差异应是合理的实验内变化，而不是随机失真或完全换类。

用一句话概括：

`保留实验风格与主要结构，改变生物前景内容。`

## 2. 问题的第一性原理拆解

一张显微镜图像可以近似拆成四部分：

1. 成像风格
- brightfield / 单通道荧光 / 多通道荧光
- 背景亮度、噪声、模糊、对比度、颜色映射

2. 布局与版式
- 裁剪、视角、缩放、比例尺、字母、红框、箭头

3. 生物前景
- 细胞、类器官、组织区域、荧光信号区域
- 数量、大小、形状、边界、纹理、密度、强弱

4. 图像后处理痕迹
- 面板风格、标注、压缩痕迹、实验图导出习惯

真正要固定的是：

- 成像风格
- 实验类型
- 版式与标注
- 主要空间结构关系

真正要变化的是：

- 生物前景信息

所以本任务不是普通 image-to-image，而是：

`受结构约束的条件生成`

## 3. 系统总架构

建议采用四层系统：

1. 图像解析层
2. 中间表示层
3. 结构编辑层
4. 图像重建层

流程如下：

`参考图 -> 解析 -> 结构表示 -> 编辑结构 -> 条件重建 -> 结果图`

## 4. 系统分层设计

### 4.1 图像解析层

目标：

- 从参考图中分离出“必须保留的部分”和“允许变化的部分”。

输入：

- 一张参考显微镜图 `reference_image`

输出：

- `style_bucket`
- `content_type`
- `annotation_mask`
- `foreground_mask`
- `layout_info`
- `signal_statistics`

说明：

- `style_bucket` 表示成像风格类别。
- `content_type` 表示生物前景结构类型。
- `annotation_mask` 表示比例尺、字母、红框、箭头等不可变区域。
- `foreground_mask` 表示生物前景区域。
- `layout_info` 表示裁剪、视角、对象的大体分布范围。
- `signal_statistics` 表示灰度或荧光通道的统计分布。

### 4.2 中间表示层

目标：

- 把原始图像转换成可编辑、可参数化的结构表示。

原则：

- 中间表示不统一为单一二值草图。
- 必须按内容类型选择合适表示。

### 4.3 结构编辑层

目标：

- 对中间表示中的生物前景进行可控编辑。

原则：

- 编辑发生在结构层，不直接在像素层盲改。
- 编辑参数必须显式可控。

### 4.4 图像重建层

目标：

- 根据“原始风格 + 编辑后的结构表示”生成最终实验图。

原则：

- 重建器负责“渲染成实验图”，而不是决定哪里该变。
- 标注、背景、版式默认冻结或弱编辑。

## 5. 内容类型划分

为了覆盖 `train` 和 `test` 的真实数据，建议把图像内容分为以下几类：

### 5.1 `few_objects`

定义：

- 少量独立前景对象
- 常见为几个细胞、几个团块、几个清晰分离的结构

适合变化：

- 数量变化
- 大小变化
- 位置变化
- 形状变化
- 长宽比变化
- 明暗变化

不适合：

- 用大片区域模型来处理

### 5.2 `many_objects`

定义：

- 多个小对象、较密集散点、较多重复性前景单元

适合变化：

- 局部数量增减
- 密度变化
- 分布变化
- 聚散程度变化
- 单体亮度变化

不适合：

- 过强的单实例精细形状编辑

### 5.3 `mixed_cluster`

定义：

- 团块、类器官、聚团、复合结构

适合变化：

- 外轮廓变化
- 内部纹理变化
- 局部凸起和凹陷
- 局部区块排列变化
- 内部信号层次变化

不适合：

- 简单理解成“几个细胞数目变化”

### 5.4 `large_region`

定义：

- 大片连续区域、组织样区域、面状结构

适合变化：

- 区域边界波动
- 厚薄变化
- 局部纹理变化
- 染色或信号强弱变化
- 子区域对比变化

不适合：

- 用“对象计数”的方式表达差异

## 6. 中间表示设计

### 6.1 通用表示

所有类型都应输出：

- `foreground_mask`
- `annotation_mask`
- `background_style_stats`
- `style_bucket`
- `content_type`

### 6.2 `few_objects` 的中间表示

建议表示：

- 实例分割图 `instance_map`
- 中心点列表 `centers`
- 对象尺寸表 `size_table`
- 对象形状轮廓 `contours`

示例参数：

- `count`
- `center_x, center_y`
- `major_axis`
- `minor_axis`
- `rotation`
- `intensity_mean`
- `boundary_softness`

### 6.3 `many_objects` 的中间表示

建议表示：

- 密度图 `density_map`
- 热点图 `hotspot_map`
- 局部聚类图 `cluster_map`
- 对象点集 `point_set`

示例参数：

- `density_scale`
- `cluster_strength`
- `local_count_delta`
- `dispersion`
- `signal_mean`

### 6.4 `mixed_cluster` 的中间表示

建议表示：

- 外轮廓 mask `cluster_mask`
- 边界图 `boundary_map`
- 内部区域分区图 `region_partition`
- 内部纹理引导图 `texture_prior`

示例参数：

- `boundary_jitter`
- `compactness`
- `protrusion_strength`
- `internal_contrast`
- `subregion_shift`

### 6.5 `large_region` 的中间表示

建议表示：

- 区域分割图 `region_map`
- 边界图 `edge_map`
- 骨架图 `skeleton_map`
- 厚度图 `thickness_map`
- 强度场 `signal_field`

示例参数：

- `thickness_scale`
- `boundary_wave`
- `region_offset`
- `signal_gain`
- `local_texture_strength`

### 6.6 荧光图的额外表示

对于荧光图，仅用轮廓不够，还应附加：

- 通道强度图 `channel_response_map`
- 热点响应图 `fluorescence_hotspot_map`
- 通道间比例 `channel_ratio`

示例参数：

- `blue_gain`
- `green_gain`
- `red_gain`
- `hotspot_density`
- `local_channel_shift`

## 7. 结构编辑器设计

### 7.1 编辑器目标

把参考图表示 `R` 编辑为新表示 `R'`，要求：

- 与原表示同类
- 保留大结构与实验语义
- 前景在合理范围内变化

### 7.2 编辑方式

采用参数化编辑，而不是纯文本描述：

- `count_delta`
- `size_scale`
- `shape_jitter`
- `position_shift`
- `density_scale`
- `boundary_wave`
- `texture_strength`
- `signal_gain`

### 7.3 内容类型对应编辑策略

#### `few_objects`

编辑器支持：

- 新增或删除少量对象
- 调整对象位置
- 调整对象大小
- 调整对象形状
- 调整对象亮度与边界柔和度

#### `many_objects`

编辑器支持：

- 提高或降低局部密度
- 改变局部聚集模式
- 改变热点区域位置
- 改变局部分布均匀性

#### `mixed_cluster`

编辑器支持：

- 调整轮廓边界
- 调整内部区块关系
- 改变团块紧凑度
- 增加局部突出或凹陷
- 改变内部纹理层次

#### `large_region`

编辑器支持：

- 改变边界波动
- 改变局部厚薄
- 调整区域内信号强弱
- 改变子区域结构对比

## 8. 图像重建器设计

### 8.1 重建输入

- `reference_image`
- `edited_representation`
- `style_bucket`
- `annotation_mask`
- `background_style_stats`

### 8.2 重建输出

- `generated_image`

### 8.3 重建原则

- 参考图的背景和标注优先保留。
- 生物前景使用编辑后的结构表示进行重建。
- 风格由参考图提供，不允许整体风格漂移。

### 8.4 两条实现路线

#### 路线 A：结构编辑 + 风格迁移重建

特点：

- 快速验证
- 工程成本较低
- 更适合当前阶段

做法：

- 提取前景结构
- 编辑结构
- 用原图背景与风格统计做融合重建

#### 路线 B：结构条件生成

特点：

- 上限更高
- 可控性更强
- 需要更多开发成本

做法：

- 用结构图、分割图、信号图作为条件输入
- 由条件生成模型重建实验图

## 9. 推荐的最小可行实现

当前最优的开发顺序不是直接上完整生成器，而是分三步：

### Phase 1：结构解析可视化

目标：

- 先验证我们能否正确解析结构

输出：

- 前景 mask
- 标注 mask
- 内容类型
- 结构草图或结构图

验收标准：

- 人眼能看懂解析结果是否合理

### Phase 2：结构编辑器

目标：

- 在中间表示上显式施加差异

输出：

- 编辑前结构表示
- 编辑后结构表示
- 参数记录

验收标准：

- 肉眼能看出结构变化
- 变化形式与内容类型一致

### Phase 3：条件重建

目标：

- 根据编辑后的结构生成新实验图

输出：

- 最终实验图

验收标准：

- 风格像参考图
- 结构仍属同类实验
- 生物前景有肉眼可见差异

## 10. 模块清单

建议拆成以下模块：

### 模块 1：`style_classifier`

输入：

- `reference_image`

输出：

- `style_bucket`

职责：

- 判断 brightfield / 单通道荧光 / 多通道荧光

### 模块 2：`content_classifier`

输入：

- `reference_image`
- `foreground_mask`

输出：

- `content_type`

职责：

- 判断 `few_objects / many_objects / mixed_cluster / large_region`

### 模块 3：`structure_extractor`

输入：

- `reference_image`

输出：

- `representation`

职责：

- 提取当前内容类型对应的中间表示

### 模块 4：`structure_editor`

输入：

- `representation`
- `edit_policy`
- `edit_params`

输出：

- `edited_representation`

职责：

- 对结构做参数化编辑

### 模块 5：`annotation_preserver`

输入：

- `reference_image`

输出：

- `annotation_mask`

职责：

- 冻结比例尺、字母、箭头、红框等区域

### 模块 6：`image_renderer`

输入：

- `reference_image`
- `edited_representation`
- `style_bucket`
- `annotation_mask`

输出：

- `generated_image`

职责：

- 生成最终实验图

### 模块 7：`quality_evaluator`

输入：

- `reference_image`
- `generated_image`
- `representation`
- `edited_representation`

输出：

- `quality_report`

职责：

- 评价是否保持风格
- 评价是否保留主要结构
- 评价差异是否足够

## 11. 质量评价指标

建议分三类指标：

### 11.1 相似性指标

- 风格一致性
- 布局一致性
- 标注一致性
- 主结构保留度

### 11.2 差异性指标

- 前景面积差异
- 前景数量差异
- 结构参数差异
- 局部纹理差异
- 通道强度差异

### 11.3 失败指标

- 前景被抹掉
- 整体变空白
- 标注损坏
- 完全脱离原实验类型
- 背景大范围漂移

## 12. 当前阶段最合理的工程路线

结合现有仓库和当前问题，建议优先做：

1. 结构解析模块
2. 结构可视化输出
3. 结构编辑器
4. 简单重建器
5. 再评估是否需要更强的条件生成模型

原因：

- 现在的主要矛盾不是“模型不够大”，而是“结构变化不可控”。
- 只要结构表示和结构编辑器做出来，后面的生成问题会简单很多。

## 13. 核心结论

本问题的正确建模方式不是：

- 直接让模型根据原图做一点变化

而是：

- 先提取参考图中必须保留的结构与风格
- 再提取可变化的生物前景表示
- 对前景表示做可控编辑
- 最后根据编辑后的表示重建实验图

用公式表达就是：

- 从参考图提取 `S` 和 `B`
  - `S` = 风格与结构骨架
  - `B` = 生物前景表示
- 对 `B` 做编辑得到 `B'`
- 用 `S + B'` 重建生成图

最终目标是：

`生成与参考图结构风格相似，但其中生物前景信息不同的实验图。`
