# Micro Image Generation Rule

## 目标

基于原始显微镜图像生成 AI 图像，要求：

- 与原图保持同一实验结构。
- 保持同一实验结果类型、成像风格和整体语义。
- 保持主要生物前景对象与整体布局相似，但不要求逐像素一致。
- 允许局部差异，例如数量、大小、形状、内部纹理、灰度/信号强弱、局部分布变化。
- 最终结果应看起来像“同一次实验的另一张合理采样图”，而不是完全不同的新图，也不是原图的逐像素复制。

## 发现的问题

在 `case-1` 中，原图的细胞被生成结果整体抹掉，只保留了平滑背景和字母标注。

根本原因：

1. 原图属于低对比度 brightfield 显微图，细胞与背景灰度差较弱。
2. 纯 prompt 约束不足，模型容易把细胞识别成弱纹理噪声并直接平滑删除。
3. 原始生成结果尺寸发生变化，说明模型在“重绘整张图”，而不是严格保留原图结构。

## 当前生成策略

当前策略不是直接相信模型输出，而是采用：

`风格分类 + 内容类型分类 + 类型化 prompt + 结构保护融合`

### 1. 数据使用策略

- 原始数据来自：
  - `micro/train/Micro/image`
  - `micro/test/Micro/image`
- 默认目标总量：
  - `train = 2400`
  - `test = 600`
  - 总计 `3000`
- 测试时先小批量运行，不直接跑满量。

### 2. 风格分桶

为避免不同显微图风格比例失衡，先对图像做粗分类：

- `grayscale`
- `fluorescence_single_channel`
- `fluorescence_multichannel`

抽样时按原始数据分布比例取样，避免测试样本只集中在单一风格。

### 3. 内容类型分层

待处理图像不能统一按“几个细胞”理解，因此在风格分类之外，再按内容结构做粗分类：

- `few_objects`
  - 少量独立前景对象
- `many_objects`
  - 多个小对象或较密集的小结构
- `mixed_cluster`
  - 团块、类器官、聚团、复合结构
- `large_region`
  - 大片连续区域、组织样区域、面状结构

这里的统一对象概念不是“细胞”，而是：

- `生物前景对象`

这样规则能同时覆盖单细胞、聚团、组织区域和部分荧光结构图。

### 4. Prompt 规则

prompt 的核心原则：

- 保持实验类型不变。
- 保持成像风格不变。
- 不能把主要生物前景整体抹掉。
- 不能新增大结构。
- 可以根据图像类型，对前景对象进行合理变化。
- 保持原图裁剪、缩放、视角、亮度、背景、模糊、噪声、标注不变。
- 差异形式由图像类型决定，而不是统一限定为“细胞数量变化”。

对 brightfield 图额外强调：

- 必须保留弱对比度前景纹理。
- 不能把前景区域变成空白背景。

### 5. 各内容类型允许的变化

#### `few_objects`

- 允许变化：
  - 数量变化
  - 大小变化
  - 形状变化
  - 宽度/长宽比变化
  - 明暗变化
  - 相对位置变化
- 不允许：
  - 整体场景被替换成完全不同结构
  - 主要对象全部消失

#### `many_objects`

- 允许变化：
  - 局部密度变化
  - 局部数量增减
  - 分布模式变化
  - 小对象亮度和形态波动
- 不允许：
  - 全场被抹平为空白背景
  - 完全失去原有场景密集度特征

#### `mixed_cluster`

- 允许变化：
  - 团块外轮廓轻微变化
  - 内部纹理变化
  - 局部凸起/凹陷
  - 区域内部明暗与层次变化
- 不允许：
  - 团块整体消失
  - 聚团结构被改成完全不同语义对象

#### `large_region`

- 允许变化：
  - 边界波动
  - 厚薄变化
  - 局部纹理变化
  - 染色/信号强弱变化
  - 子区域对比变化
- 不允许：
  - 大区域拓扑被完全改写
  - 区域被整体抹除

### 6. 模型输出处理规则

模型原始输出不直接作为最终结果，而是先经过以下约束：

1. 将模型输出强制缩放回原图尺寸。
2. 让模型输出的颜色/灰度统计尽量贴近原图。
3. 从原图中自动检测生物前景区域。
4. 根据前景覆盖率、连通区域数量和最大区域比例估计内容类型。
5. 如果检测到模型输出前景明显坍塌，判定为“结构丢失”。
6. 按内容类型选择不同融合强度，而不是所有图都用同一种保护方式。

### 7. 前景掩膜规则

为了保住结构，先从原图中估计生物前景区域：

- 通过大尺度平滑估计背景。
- 计算图像相对背景的亮/暗响应。
- 根据响应强度提取显著前景区域。
- 做膨胀和孔洞填充。
- 去掉面积太小、太大或贴边的异常连通区域。
- 用前景覆盖率、连通区域数量、最大区域占比来判断内容类型。

这个掩膜用于限制模型编辑范围，避免整张图被改坏。

### 8. 融合规则

最终图像采用“类型化融合”：

- `few_objects`
  - 允许更高的生成占比
  - 允许更明显的位置和轮廓变化
- `many_objects`
  - 保留整体密度场
  - 允许局部对象分布变化
- `mixed_cluster`
  - 保留聚团主结构
  - 允许内部纹理和局部轮廓变化
- `large_region`
  - 更偏向结构保护
  - 变化主要体现在区域边界和内部纹理

这样做的目的：

- 保住原图实验结构。
- 给出与图像类型匹配的局部差异。
- 避免“整块抹空”“对象消失”“背景漂移”等失败。

## 当前策略允许的变化

允许变化的部分：

- 前景对象数量变化。
- 前景对象大小和形状变化。
- 局部深浅或信号强弱变化。
- 内部纹理变化。
- 局部分布变化。
- 局部结构变化。

不允许变化的部分：

- 大结构消失或新增。
- 比例尺、字母标注、红框、箭头等被改变。
- 整体背景亮度和实验风格发生明显漂移。
- 生成结果脱离原始实验类型。

## 判断一张结果是否合格

合格结果应满足：

- 一眼看上去与原图是同一种实验场景。
- 主要前景对象都还在。
- 整体语义和布局相似，但允许局部位置和局部结构变化。
- 背景没有被大面积重绘。
- 与原图相比存在真实且合理的局部差异。

不合格结果包括：

- 主要前景对象被抹掉。
- 整图变空白。
- 生成出原图没有的新结构。
- 标注或比例尺被改掉。
- 结果不再像同一种实验结果。

## 当前脚本职责

### `micro/micro_qwen_dataset_pipeline.py`

负责批量流程：

- 抽样
- 风格分桶
- 内容类型分类
- 调用 Qwen image edit
- 检测前景
- 按类型融合修正
- 保存最终结果、raw 输出、清单、预览图

### `micro/run_micro_qwen_test.sh`

负责测试运行：

- 用较小样本先看效果
- 输出最终图和 raw 模型输出

### `micro/repair_case_pair.py`

负责修复单个 case：

- 输入原图和已有生成图
- 进行结构保留融合
- 输出修复结果

## 后续调参原则

如果结果仍然“过于像原图”，则：

- 可以提高对应内容类型下的生成融合占比。
- 可以适当增加推理步数。

如果结果仍然“前景被削弱或抹掉”，则：

- 降低 prompt 引导强度。
- 降低生成融合强度。
- 提高前景保护范围。
- 对 brightfield 图使用更保守的结构保护。
- 对 `large_region` 和 `mixed_cluster` 使用更高的结构保留权重。

## 结论

后续生成必须遵循一个核心原则：

`先保结构，再引入差异。`

也就是说，AI 图像不是去“重新画一张新图”，而是在原图实验语义和主要结构稳定的前提下，根据图像内容类型生成合理变化。
