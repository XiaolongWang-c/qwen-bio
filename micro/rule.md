# Micro Image Generation Rule

## 目标

基于原始显微镜图像生成 AI 图像，要求：

- 与原图保持同一实验结构。
- 保持主要细胞/类器官/组织区域的数量、位置、外轮廓和整体布局基本一致。
- 允许局部细节存在差异，例如内部纹理、灰度分布、边界柔和度、局部强弱变化。
- 最终结果应看起来像“同一次实验的另一张合理采样图”，而不是完全不同的新图，也不是原图的逐像素复制。

## 发现的问题

在 `case-1` 中，原图的细胞被生成结果整体抹掉，只保留了平滑背景和字母标注。

根本原因：

1. 原图属于低对比度 brightfield 显微图，细胞与背景灰度差较弱。
2. 纯 prompt 约束不足，模型容易把细胞识别成弱纹理噪声并直接平滑删除。
3. 原始生成结果尺寸发生变化，说明模型在“重绘整张图”，而不是严格保留原图结构。

## 当前生成策略

当前策略不是直接相信模型输出，而是采用：

`原图结构约束 + 模型编辑 + 后处理融合`

### 1. 数据使用策略

- 原始数据来自：
  - `micro/train/Micro/image`
  - `micro/test/Micro/image`
- 默认目标总量：
  - `train = 2400`
  - `test = 600`
  - 总计 `3000`
- 测试时先小批量运行，不直接跑满量。

### 2. 风格分桶

为避免不同显微图风格比例失衡，先对图像做粗分类：

- `grayscale`
- `fluorescence_single_channel`
- `fluorescence_multichannel`

抽样时按原始数据分布比例取样，避免测试样本只集中在单一风格。

### 3. Prompt 规则

prompt 的核心原则：

- 不能删除已有细胞。
- 不能新增大结构。
- 可以明显移动细胞。
- 保持原图裁剪、缩放、视角、亮度、背景、模糊、噪声、标注不变。
- 只允许细胞内部纹理、边缘柔和度、局部灰度存在轻微变化。

对 brightfield 图额外强调：

- 必须保留弱对比度细胞纹理。
- 不能把细胞区域变成空白背景。

### 4. 模型输出处理规则

模型原始输出不直接作为最终结果，而是先经过以下约束：

1. 将模型输出强制缩放回原图尺寸。
2. 让模型输出的颜色/灰度统计尽量贴近原图。
3. 从原图中自动检测前景区域，也就是细胞/类器官/组织区域。
4. 如果检测到模型输出前景明显坍塌，判定为“结构丢失”。
5. 最终结果只在原图前景区域内融合模型生成内容，背景区域优先保留原图。

### 5. 前景掩膜规则

为了保住结构，先从原图中估计细胞区域：

- 通过大尺度平滑估计背景。
- 计算图像相对背景的亮/暗响应。
- 根据响应强度提取显著前景区域。
- 做膨胀和孔洞填充。
- 去掉面积太小、太大或贴边的异常连通区域。

这个掩膜用于限制模型编辑范围，避免整张图被改坏。

### 6. 融合规则

最终图像采用“低频替换，高频保留”的策略：

- 原图高频信息：主要保留结构边缘、弱纹理、细胞外轮廓。
- 生成图低频信息：提供轻微的灰度变化和内部风格变化。
- 背景区域默认保持原图。

这样做的目的：

- 保住原图实验结构。
- 给出局部差异。
- 避免“整块抹空”“细胞消失”“背景漂移”等失败。

## 当前策略允许的变化

允许变化的部分：

- 细胞内部纹理轻微变化。
- 局部深浅变化。
- 边界清晰度轻微变化。
- 微小局部形态波动。

不允许变化的部分：

- 细胞数量大幅变化。
- 细胞整体位置明显移动。
- 大结构消失或新增。
- 比例尺、字母标注、红框、箭头等被改变。
- 整体背景亮度和实验风格发生明显漂移。

## 判断一张结果是否合格

合格结果应满足：

- 一眼看上去与原图是同一种实验场景。
- 主要前景对象都还在。
- 位置关系基本一致。
- 背景没有被大面积重绘。
- 与原图相比存在轻微但真实的局部差异。

不合格结果包括：

- 细胞被抹掉。
- 整图变空白。
- 细胞位置明显漂移。
- 生成出原图没有的新结构。
- 标注或比例尺被改掉。

## 当前脚本职责

### `micro/micro_qwen_dataset_pipeline.py`

负责批量流程：

- 抽样
- 风格分桶
- 调用 Qwen image edit
- 检测前景
- 融合修正
- 保存最终结果、raw 输出、清单、预览图

### `micro/run_micro_qwen_test.sh`

负责测试运行：

- 用较小样本先看效果
- 输出最终图和 raw 模型输出

### `micro/repair_case_pair.py`

负责修复单个 case：

- 输入原图和已有生成图
- 进行结构保留融合
- 输出修复结果

## 后续调参原则

如果结果仍然“过于像原图”，则：

- 可以略微提高融合区域中的生成占比。
- 可以适当增加推理步数。

如果结果仍然“细胞被削弱或抹掉”，则：

- 降低 prompt 引导强度。
- 降低生成融合强度。
- 提高前景保护范围。
- 对 brightfield 图使用更保守的结构保护。

## 结论

后续生成必须遵循一个核心原则：

`先保结构，再引入差异。`

也就是说，AI 图像不是去“重新画一张新图”，而是在原图结构稳定不变的前提下，只生成局部合理变化。
