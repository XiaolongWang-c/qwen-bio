# blot 图像生成方案

## 1. 当前采用的主方案

当前正式采用的方案是：

`参考图粗粒度统计提取 -> 低维统计模型 -> 约束采样 -> 直接绘制生成`

该方案已经替代此前效果较差的“复杂逐条带重建 / 草图重建”路线。原因很明确：

1. 旧方案自由度过高，容易产生伪泳带、边角异常结构、矩形补丁和不真实排布。
2. blot / gel 图像本身是强结构化图像，更适合用低自由度、强约束、直接绘制的方法生成。
3. 当前方案在小批量测试中已经验证，条带形态、背景风格、模糊程度和整体稳定性都明显更好。

本方案的目标不是像素级复刻参考图，而是：

1. 保留参考图的整体实验风格。
2. 保留参考图的泳道数量、泳道间距、条带密度、背景风格和模糊等级。
3. 生成一张新的、结构相似但结果不同的 blot 图像。
4. 模拟“同一实验体系下的另一组结果”。

## 2. 数据与划分

原始数据位于：

- `blot/train/image`
- `blot/test/image`

当前固定使用如下子集：

1. 从原始训练集抽取 `2400` 张。
2. 从原始测试集抽取 `600` 张。
3. 合计 `3000` 张。

采用该划分的原因：

1. 保持原有训练集和测试集来源不变。
2. 避免重新打散带来的潜在数据泄漏。
3. 便于后续复现实验。

## 3. 当前方案的核心思想

### 3.1 不做的事情

当前方案明确不做以下事情：

1. 不在原图上直接改条带。
2. 不逐像素重建条带结构。
3. 不做复杂的逐条带几何拟合和局部 patch 合成。
4. 不依赖草图作为必须中间层。

### 3.2 当前真正做的事情

当前方案只从参考图提取对生成最稳定、最关键的统计信息，例如：

1. 图像宽高
2. 泳道数量
3. 泳道中心位置
4. 泳道平均间距
5. 泳道平均宽度
6. 每泳道条带数量的统计
7. 条带纵向位置候选池
8. 条带强度均值
9. 条带厚度均值、厚度方差、细条带比例
10. 背景亮度均值
11. 背景噪声强度
12. 图像模糊程度

这些量被组织成一个低维统计模型，然后围绕该模型做小幅约束采样，再直接绘制新图。

## 4. 为什么当前方案效果更好

相比之前失败的方案，当前方案效果更好的原因主要有以下几点：

### 4.1 结构自由度更低

泳道数、泳道间距和泳道宽度都被参考图统计量强约束，因此：

1. 不容易出现乱序排布。
2. 不容易出现泳道位置失真。
3. 不容易出现“随机画了一堆条带”的假感。

### 4.2 条带生成方式更贴近真实 blot

当前条带不是“局部矩形 patch 再贴回去”，而是：

1. 使用横向拉长的条带核直接绘制。
2. 条带两端做轻微自然衰减。
3. 条带边缘做适度模糊。
4. 条带中心对比度比边缘更强。
5. 条带允许极弱弯曲，但不允许夸张变形。

这更接近真实蛋白质凝胶图像中的实验条带。

### 4.3 背景生成更稳定

背景不再依赖复杂的前景剥离，而是直接根据参考图统计量构造：

1. 灰底背景
2. 轻微噪声
3. 轻微亮度渐变
4. 轻度低频纹理

因此：

1. 四周边缘更干净。
2. 不容易带入原图残影。
3. 不容易产生明显的补丁痕迹。

### 4.4 模糊程度跟参考图自适应

模糊不再统一处理，而是根据参考图清晰度估计后自适应设置，因此：

1. 原图清晰的样本，生成结果不会过度模糊。
2. 原图本身较模糊的样本，生成结果也能保持合适模糊感。

## 5. 生成流程

当前正式流程如下：

```text
参考图
  -> 粗粒度统计提取
  -> 低维统计模型
  -> 约束参数采样
  -> 背景生成
  -> 条带直接绘制
  -> 全局轻微模糊
  -> 最终新图
```

## 6. 步骤一：3000 张子集筛选

### 6.1 抽样规则

1. 从 `blot/train/image` 抽取 `2400` 张。
2. 从 `blot/test/image` 抽取 `600` 张。
3. 使用固定随机种子。
4. 保存抽样文件清单，保证结果可复现。

### 6.2 输出内容

需要保存：

1. 训练集抽样清单
2. 测试集抽样清单
3. 随机种子
4. 生成日志

## 7. 步骤二：参考图粗粒度统计提取

### 7.1 提取目标

每张参考图需要提取以下统计量：

1. 图像宽高
2. 泳道中心位置列表
3. 泳道数量
4. 泳道平均间距
5. 泳道平均宽度
6. 每泳道条带位置列表
7. 每泳道条带数量均值
8. 条带纵向候选位置池
9. 条带强度均值
10. 条带厚度均值
11. 条带厚度标准差
12. 细条带比例
13. 背景亮度均值
14. 背景噪声水平
15. 模糊强度
16. 图像清晰度得分

### 7.2 提取方法

采用低复杂度传统图像处理：

1. 灰度化
2. 轻微高斯平滑
3. 使用列投影检测泳道峰
4. 使用行投影检测条带峰
5. 使用峰宽估计条带厚度
6. 使用背景区域统计估计亮度和噪声
7. 使用拉普拉斯方差估计清晰度

### 7.3 元数据格式

建议每张参考图保存一个 `json` 元数据文件，至少包括：

```json
{
  "image_name": "example.png",
  "split": "train",
  "width": 298,
  "height": 48,
  "lane_positions": [24, 71, 118, 165, 212],
  "lane_count": 5,
  "lane_width": 26,
  "lane_spacing": 47.0,
  "band_mean": 1.0,
  "band_y_pool": [22],
  "intensity_mean": 0.21,
  "thickness_mean": 3.8,
  "thickness_std": 0.9,
  "thin_band_ratio": 0.6,
  "background_mean": 0.77,
  "background_noise": 0.02,
  "blur_sigma": 0.86,
  "sharpness_score": 1.42
}
```

## 8. 步骤三：低维统计模型与约束采样

### 8.1 统计模型内容

每张参考图构建一个低维生成模型，核心参数包括：

1. 泳道数
2. 泳道宽度
3. 泳道间距
4. 每泳道条带数
5. 条带纵向位置候选池
6. 条带厚度分布
7. 细条带比例
8. 条带强度均值
9. 背景亮度
10. 背景噪声
11. 模糊强度

### 8.2 参数采样原则

采样必须保守，不能过度偏离参考图：

1. 泳道数只允许小幅波动。
2. 泳道宽度和泳道间距只允许轻微扰动。
3. 条带数量围绕参考均值采样。
4. 条带纵向位置优先从参考图候选池采样，再做很小偏移。
5. 条带厚度需要同时保留粗条带和细条带比例。
6. 模糊强度必须跟随参考图清晰度自适应变化。

## 9. 步骤四：直接绘制生成

### 9.1 背景生成

背景直接由统计模型生成：

1. 基础灰底
2. 轻微高斯噪声
3. 轻微纵向/横向亮度渐变
4. 很弱的低频纹理

要求：

1. 背景整体风格与参考图接近。
2. 图像四周边缘应保持干净。
3. 不能出现明显暗角或边缘发黑。

### 9.2 条带绘制

条带采用直接绘制方式：

1. 条带主体是横向拉长的带状核
2. 两端做轻微自然衰减
3. 条带中心对比度高于边缘
4. 条带允许极弱弯曲，但不能明显弯折
5. 条带横向长度应接近真实泳道宽度
6. 条带厚度由参考图统计控制

### 9.3 模糊与增强

模糊处理要求：

1. 原图清晰，则生成图应偏清晰
2. 原图模糊，则生成图可适度模糊
3. 不允许统一把所有图都做重模糊

### 9.4 细条带与粗条带共存

当前方案明确要求生成器保留不同厚度条带：

1. 不能所有条带都偏粗
2. 需要根据参考图细条带比例生成细带
3. 宽条带与细条带可以在不同图中共存

## 10. 质量控制

### 10.1 自动检查项

建议加入以下自动检查：

1. 图像尺寸是否合法
2. 图像是否为空白
3. 条带是否全部消失
4. 条带是否全部偏粗
5. 条带是否全部过度模糊
6. 背景是否过曝或过暗
7. 边缘是否出现异常发黑
8. 是否出现明显矩形边缘或补丁痕迹

### 10.2 人工抽查重点

人工抽查时重点看：

1. 条带边缘是否自然
2. 条带是否过圆或过团
3. 条带是否过度模糊
4. 是否保留了细条带
5. 泳道排布是否合理
6. 背景边缘是否干净

## 11. 当前方案相对旧方案的结论

当前方案结论如下：

1. 已经确认优于旧的复杂重建方案。
2. 当前方案更稳定、更容易调参、更符合 blot 图像的统计结构。
3. 当前方案适合直接扩展到 3000 张批量生成。
4. 后续优化应集中在细节调参，而不应再回到旧的复杂重建路线。

## 12. 本阶段最终产物

本阶段完成后，期望得到：

1. 一个固定的 3000 张 blot 子集
2. 每张参考图对应的统计参数元数据
3. 每张参考图对应的 1 张新生成 blot 图
4. 抽样记录和生成日志
5. 可供人工抽查的 montage 或预览样本

以上方案作为当前正式执行基线。后续如需继续优化，应在不改变当前“粗粒度统计提取 + 低维统计模型 + 直接绘制”主路线的前提下，做局部精修。
